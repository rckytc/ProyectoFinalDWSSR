# Proyecto Final DWSSR

## Descripción

Este proyecto consiste en desarrollar una aplicación para monitorear variables relacionadas con el uso y comportamiento del agua, almacenar los datos y detectar posibles anomalías.

El sistema se desarrollará por etapas, utilizando herramientas de desarrollo web, comunicación mediante MQTT y almacenamiento de información.

## Objetivo general

Desarrollar un sistema de monitoreo que permita visualizar datos en tiempo real, almacenar registros y detectar comportamientos anormales mediante algoritmos programados en JavaScript.

## Tecnologías previstas

- Node.js y Express para el servidor.
- Vite y Tailwind CSS para la interfaz web.
- MQTT para la comunicación de datos.
- MongoDB para el almacenamiento.
- JavaScript para el procesamiento y la detección de anomalías.

## Estado del proyecto

**Etapa inicial:** configuración del repositorio y preparación del entorno de desarrollo.

Los datos simulados, si se utilizan durante el desarrollo, se identificarán claramente como simulados. La integración con componentes físicos se documentará según los recursos disponibles.
